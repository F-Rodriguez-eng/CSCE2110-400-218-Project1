# CSCE2110-400-218-Project1

#Project 1 - Campus Resource Reservation System

##Overview:
CSCE 2110's Project 1 is a Campus Resource Reservation System made in C++, allowing students to reserve campus resources such as study rooms, laptops, calculators, lab equipment, and tutoring appointments.

The system provides function to resource management, reservation management, waiting list processing, cancellation history tracking, and report generation.

The project demonstrates an understanding of object-oriented programming standards. Additionally, it showcases data structure fundamentals such as linked lists, queues, and stacks.
